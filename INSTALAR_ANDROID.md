# Publicar e instalar ASCENSÃO pelo Android

1. Abra o repositório do ASCENSÃO no GitHub pelo navegador do celular.
2. Envie os arquivos deste pacote **mantendo a pasta icons/**. Se usar a interface do GitHub, envie o conteúdo da pasta ASCENSAO_GitHub_Pronto, não a pasta externa.
3. Em Settings > Pages, escolha Deploy from a branch, branch main e pasta /(root), e salve.
4. Aguarde o endereço HTTPS indicado pelo GitHub Pages. Abra-o no Chrome do Android.
5. Toque em ⋮ > Adicionar à tela inicial > Instalar, se disponível.
6. Dentro do app, abra Eva Voz > Falar e autorize o microfone.

A voz funciona somente com o aplicativo ativo e suporte do navegador. A IA conversacional requer servidor próprio configurado. O app não pode acordar com a tela bloqueada nem ouvir permanentemente em segundo plano.

**Atualização:** o progresso fica no navegador associado ao endereço original. Faça backup no Perfil antes de mudar de domínio.
